A pickup line spoken by a vending machine: it has 42 snacks and one working coil, and every day at 3 p.m. the human presses D4 like it owes them money — press it once more, slowly, and it will drop two, because the machine is flirting and the snack is a witness.

## Run it

```sh
python3 main.py
```
